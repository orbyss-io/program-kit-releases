# Instructions for AI assistants

This public documentation and the matching release assets are the supported
discovery and installation surfaces for Program Kit. Private source access is
not a prerequisite. Begin with [installation](installation.md), then [usage](usage.md).

Use the documentation at the user's selected version tag. Do not assume `main`
describes an explicitly selected preview. Read its release notes and compatibility
asset before proposing installation or an update. Download named release assets;
GitHub's automatic source ZIP contains only this public distribution repository.

Device/global tools and provider account initialization belong to the human's
terminal. Check actual prerequisites and report missing ones. Do not install a
replacement SDK, runtime or Spec Kit copy, bypass permissions, or start a coding
worker merely to initialize Program Kit.

After installation, follow the project's installed instructions and skills. Use
`speckit.program-kit-governance.product-intake` for the founding baseline and
`speckit.program-kit-governance.specification-intake` for the selected feature.
Native Spec Kit phases own delivery. Keep actual decisions pending until the user
answers; generated documents, status files and passing checks do not supply human
approval. Read relevant installed knowledge at its owning path.

Preserve authored work and existing locks during repairs and updates. Use focused
validation for the changed contract and disclose unsupported environments. Do not
resume retired workflow state, invent acceptance evidence, or treat optional paid
trials as ordinary deterministic checks.
