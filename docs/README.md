# Program Kit documentation

Program Kit helps a person and their coding assistant establish a product baseline,
choose architecture and dependencies, and deliver features through native Spec Kit
phases. Its installed guidance and deterministic helpers support that collaboration.

Start here:

- [Download and install](installation.md)
- [First project and everyday use](usage.md)
- [Architecture and responsibilities](architecture.md)
- [Updates and compatibility](upgrading.md)
- [Instructions for AI assistants](ai-assistants.md)
- [Building-block selection](building-block-selection.md)
- [Coding context](coding-context.md), [patterns](coding-patterns.md), and [scaffolding](coding-scaffolding.md)
- [Consumer engineering](consumer-engineering.md) and [engineering locations](engineering-locations.md)
- [Knowledge discovery](knowledge-discovery.md) and [UI theming](ui-theming.md)

Versioned documentation is available by selecting the matching release tag in this
repository. `main` is the discovery surface and stable catalog channel; previews
are selected explicitly by tag. Documentation, downloadable scripts and templates are covered by the
license included with their release. Development plans and contributor records
are maintained privately.
